# v1.1 更新说明（草稿）

从 v1.0 内测（10-25 00:32）到 v1.1，共 47 次提交。下面按「新增 / 改进 / 修复」分类，
可直接粘进后台「公告 → 更新日志」，版本号填 `v1.1`。

---

## 新增

- **公告与更新日志**：管理员可发布公告和版本更新，访客进站收到一次提示
- **帮助中心**：Markdown 语法速查、如何发布成果、打卡与积分、邀请同学、常见问题五个主题
- **帮助资料上传**：管理员在后台上传 PDF / 安装包，自动出现在 Markdown 帮助页，支持删除
- **头像上传**：个人资料里可直接拖图上传，全站（侧栏、个人页、成员卡）显示头像
- **首页最新笔记**：展示最近 5 篇学习内容，点开看全文
- **笔记页 AI 问答**：学习笔记也能「问问 AI」，与项目问答共用额度与分档
- **顶栏面包屑**：显示当前所在位置（首页 / 成果 / 详情）
- **图片存 OSS**：上传的图片进对象存储，不再占用服务器磁盘
- **异地备份**：每日数据库备份同步到 OSS，保存 30 天
- **一键部署脚本**：本地一条命令打包上传并只重建改动的服务

## 改进

- **导航改成侧栏**：桌面可折叠成图标栏，手机变抽屉；入口按「浏览 / 发布 / 管理」分组
- **全站视觉重做**：统一标题字号与间距，卡片加跟随鼠标的倾斜效果
- **AI 面板重做**：入口改成显眼卡片，面板改成聊天气泡，加了思考态与流式光标
- **上传队列**：拖拽上传，显示真实进度条，失败可重试
- **密码框**：逐字切换明文/圆点，带强度条
- **静态资源缓存**：`_next/static` 缓存一年，二次访问只传 HTML
- **构建加速**：Maven / apk / pip / npm 全部改走国内镜像，首次构建从 20 分钟降到 5 分钟
- **站点更名**：确定为「欲晓」，取自「东方欲晓，莫道君行早」
- **登录体验**：错误提示按原因区分（额度用完 / 密码错 / 网络异常）

## 修复

- 摘要生成失败：密钥多了一个字符导致 401，同时补上「摘要不落库」的缺陷
- 部署后 502：容器重建后 nginx 仍指向旧 IP，改为部署后自动重启 nginx
- 数据迁移报 role 不存在：生产库缺 ai_reader 角色，初始化脚本改为随 compose 挂载
- 热力图月份标签竖排：容器宽度不足导致换行
- 打卡卡片宽度错位：`display:flex` 让内层卡片按内容收缩
- 帮助入口指错页面：侧栏「帮助」指向 Markdown 页而非帮助首页
- 页脚与公告文案过时：上线后仍写着「运行在作者本机」
- 备份文件误提交进仓库：加忽略规则并从索引移除
