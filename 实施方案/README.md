## v1.2 的架构变更（当前决策）

| 维度 | 决策 |
| --- | --- |
| API | **Spring Boot 3.4 + Java 21 + Maven**，Spring Security 负责认证授权，Flyway 管迁移，JPA 访问数据 |
| AI | **FastAPI + Python 3.12**，独立服务，Nginx 直连（不经 Spring 转发），自己限流 |
| UI | **Next.js 15**，只做页面与 SSR，不再承载业务接口 |
| 数据 | 单 PostgreSQL，api 拥有业务表，ai 只拥有 `ai_conversations` 并通过只读视图读项目 |
| 契约 | Spring 出 OpenAPI → 生成前端 TS 类型；CI 做 diff，漂移即红 |
| 部署 | Nginx 同域反代 `/` `/api` `/ai` `/uploads`；**镜像在 CI 构建，服务器只 pull** |

### 与 v1.1 的关键差异

| 项 | v1.1 | v1.2 |
| --- | --- | --- |
| 认证实现 | Node 内自建 jose 双 token | Spring Security 过滤器链 + 同一套双 token 语义 |
| 迁移 | Prisma migrate | Flyway，`ddl-auto=validate` |
| 主键 | cuid 字符串 | UUIDv7（不可枚举，可按时间排序） |
| AI 接入 | Next 内直接调模型 | FastAPI 独立服务，SSE 直连 |
| 内存 | 2 容器，宽松 | 4 容器 + PG 同机，~2.2GB，**4G 够但无余量** |
| 工期 | 10 天 | 12 天（契约流水线 + 三服务联调） |

### Spring Boot 4.x 与方案里 3.4 的差异（写代码前必须知道）

| 差异 | 说明 | 影响 |
| --- | --- | --- |
| starter 改名 | `spring-boot-starter-web` → **`spring-boot-starter-webmvc`**；Flyway 改为 **`spring-boot-starter-flyway`**；测试按模块拆成 `spring-boot-starter-*-test` | 从网上抄依赖坐标时不要用 3.x 的 |
| Spring Security 7 | 只保留 lambda DSL，`and()` 已移除；授权、CSRF 的类名不变 | 抄 3.x 的安全配置会编译失败 |
| Jackson 3 | databind 根包从 `com.fasterxml.jackson.databind` 变为 **`tools.jackson.databind`**；注解包仍为 `com.fasterxml.jackson.annotation` | 手写 `ObjectMapper` 时才需要注意 |
| Flyway 模块 | `flyway-database-postgresql` 已由 starter 带入，无需手动补 | 之前「缺依赖导致启动失败」的风险消失 |

### 积分口径（已定）

| 场景 | 基础分 | 连续奖励 | 合计 |
| --- | --- | --- | --- |
| 30 天只打卡 | 30 | +5（7 天）+10（14 天）+20（30 天）= 35 | **65** |
| 4 周 × 每周 2 篇学习内容 | 8 × 10 = 80 | — | 80 |
| 4 周内容 + 同期每天打卡（28 天） | 80 + 28 = 108 | +5（7 天）+10（14 天）= 15 | **123** |

> 修正：v1.1 §4.4 引用「4 周连续打卡再加 35 分」有误——28 天只触发 7 天与 14 天两档奖励（+15），30 天才有第三档。以本表为准。
> 测试用例按「合计」列断言：单次打卡 +1、连续 7 天 +6、第 14 天再 +10、第 30 天再 +20。

## 文档维护约定

1. **已定稿版本只读**。v1.0 不再修改，修订一律出新版本文件，保留历史。
2. **一份文档只描述一个阶段的结论**。技术栈变更不直接改 v1.1，而是出 v1.2 并标注取代关系（`superseded_by`）。
3. **改方案走 PR**：一次 PR 只改一个主题，标题 `docs: 说明`，描述里写「改了哪几条、影响哪个模块」。
4. **版本号**：功能范围或架构变化 → 次版本号 +1；仅文字修正 → 补丁号（v1.2.1），可直接改文件并在版本记录注明。
5. **front matter 必填**：`title / version / status / date / based_on`，被取代时加 `superseded_by`。
